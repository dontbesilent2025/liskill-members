# 个人故事-失败开篇多磨难

## 基本信息

- 脚本类型：故事
- 难度：2 级
- 一句话适合：有真实创业或人生重大失败史、经历过至少两轮「倒下又爬起来」并已翻身的人，用数字化钩子开篇建立真实人设。
- 必需素材：一句数字化失败钩子、早期起点与成就数字、至少两轮磨难（各带具体损失数字＋转机或贵人）、情绪最低谷细节、第二次转机、一句情绪金句
- 呈现形式：口播
- 篇幅：600–900 字，约 2–4 分钟
- 来源：cq-个人故事-失败开篇多磨难；参考视频：抖音【烧烤老板】「活了41年，我干黄了7家烧烤店，想听听我的笑话吗？」

## 什么时候选

- 有真实创业或人生失败史，能用一句带数字的话概括（干了 X 年、亏了 X 万、倒了 X 家）。
- 经历了至少两轮「磨难 → 转机」，并且已经翻身。核心是情绪过山车：先让观众跟着你沉到底，再带他们起来。
- 失败还没翻身、重心在「现在有多难」时，改选「个人故事-见证我翻盘」；想讲 15–40 年、6–12 个节点的整段人生时，改选「个人故事-我这辈子」；素材是 3–5 个跨度 1–10 年的曲折事件、而不是「成就 → 失败 → 再成就」的大起大落时，改选「个人故事-多事件曲折递进」。

## 结构链

好奇钩子（数字化概括全文）→ 早期经历＋成就 → 第一次磨难＋应对过渡 → 第一次转机（贵人相助）→ 再获成就（情绪最高点）→ 第二次磨难 → 第三次磨难叠加（情绪最低谷）→ 第二次转机 → 情绪感受金句

## 开头规则

一句话完成两件事：用数字化概括全文（活了多少年、失败了几次或几家），同时引发好奇，让陌生人想听你的故事。

句式：

- 「活了<X>年，我干黄了<X>家<店>，想听听我的笑话吗？」
- 「干了<X>年<行业>，我<亏了／倒了><数字>，……」

## 信息点模板

**好奇钩子**

1. 数字化概括（活了 X 年，干黄了 X 家／失败了 X 次）＋引发好奇。

**早期经历**

2. 起点：几岁开始，从哪里起步。

**成就**

3. 第一个成就：具体数字。
4. 更大的物质成就。

**第一次磨难**

5. 磨难起因：人祸、市场或意外。
6. 有多惨：具体损失数字。
7. 磨难时期如何过渡。

**第一次转机**

8. 转机来临：贵人、机会或坚持。
9. 贵人或机会的具体帮助。
10. 再次起来的成就。

**情绪最高点**

11. 最好的时候：数字。

**第二次磨难**

12. 磨难：共鸣性的、大家都懂的背景。
13. 具体代价。

**第三次磨难（叠加，可选）**

14. 天灾没躲过，又遇人祸。
15. 最惨的细节：数字＋情绪。
16. 情绪最低谷的状态。

**第二次转机**

17. 贵人或机会再现。
18. 出发的理由或行动。

**情绪收尾**

19. 金句升华：是感受，不是说教。

## 拍摄提示

参考视频为口播；也可以配合实景或照片。原材料未给出字幕要求。

## 常见错误

- 数字不够具体，只说「亏了很多」「开了好几家」。
- 情绪没有起伏，全在低谷或全在高峰；必须有「再获成就」这个最高点，再跌到最低谷。
- 写到「后来好了」就停，漏掉好之前又崩过的那一次。
- 金句在说教，不是在说感受。
