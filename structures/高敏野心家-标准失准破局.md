# 高敏野心家-标准失准破局

## 基本信息

- 脚本类型：故事（辅：干货）
- 难度：未标注
- 一句话适合：有原生家庭创伤、高敏感特质的创业者／内容创作者／职场野心家，讲自己低谷期在沟通或努力上标准失准的经历，并给出同频复刻和主动摩擦两个破局方法。
- 必需素材：一个沟通标准失准事件、一个努力标准失准事件、一个「最后都是你的错」的自我攻击场景、一个高位者案例
- 呈现形式：口播
- 篇幅：800–1200 字，约 3–4 分钟口播（参考原视频约 6–8 分钟、2000 字以上）
- 来源：cq-高敏野心家-标准失准破局；参考视频：未标注

## 什么时候选

- 账号面向高敏感特质的创业者、内容创作者或职场野心家，想聊自己低谷期在沟通或努力上走偏的经历。
- 能拿出四类真实素材：沟通失准、努力失准、自我攻击场景、高位者案例，各有至少一个具体场景。
- 打算给出同频复刻高位者、主动制造摩擦两个破局方法，而不只是讲经历。
- 没有自己的真实经历时不要选：所有例子必须来自真实素材，不虚构。

## 结构链

问题抛出（两个标准失准）→ 根因拆解（高敏＋创伤 → 向内归因 → 自我攻击）→ 解法 1（同频复刻高位者）→ 解法 2（主动制造摩擦＋复盘）→ 收束预告

## 开头规则

开头直接点出目标人群（高敏感野心家）和低谷期的具体痛点「不知道正常标准」，让这类人立刻感到被看见；成稿时用用户自己的沟通失准事件引出这个核心，再延伸到努力失准。

- 「<目标人群>在低谷期最容易吃亏的，是不知道正常标准：<沟通标准>和<努力标准>。」
- 「当有情绪时，分不清是对方的冒犯，还是自己<内在创伤被触发>。」

## 信息点模板

**问题抛出**（用用户的沟通失准事件引出，延伸到努力失准）

1. 目标人群标签：高敏感野心家＋低谷期场景。
2. 痛点 1，沟通标准失准：分不清情绪来源，以及倾向于忍耐的选择。
3. 痛点 2，努力标准失准：借三圈模型，要么缩在舒适区，要么直接拉到困难区。

**根因拆解**（用用户的原生家庭／自我攻击场景具体化）

1. 归因模式：高敏＋创伤 → 习惯向内归因。
2. 概念滥用：「向内求」被滥用，演变成自我攻击。
3. 原生家庭具体场景：几个「不管谁对谁错，最后都是你的错」的小例子并列。
4. 双重困境：讨好型人格，加上野心家内在看不起这份讨好，形成更深的自我攻击。

**解法 1：同频复刻高位者**（引入用户自己的高位者案例）

1. 学习力说明：高敏感是同频共振式学习，看到示范就能复刻，不是靠看懂理论。
2. 亲身例子：一次「讲理论走神、看示范就学会」的经历。
3. 风险说明：糟糕环境里的争吵暴怒也会被同频。
4. 方法：找一个高位者，用同频共振复刻。
5. 高位者定义：心态上的王者，不是职位上的领导或老板。
6. 具体榜样案例：影视角色或真实人物。

**解法 2：主动制造摩擦**（用用户的努力失准事件举例）

1. 操作说明：用和以前不一样的反应模式回应他人。
2. 两种类型示范：受委屈就压着的人 → 尝试还击；冲动的人 → 先压下去。
3. 复盘方式：用高位者心态判断，是对方真的冒犯，还是自己的创伤机制被触发。
4. 应用到努力标准：明显卡顿说明方向错了，不是不够努力。

**收束**（提炼用户内在基本盘的具体表现）

1. 重新定位：高敏感人是大后期人格，内在基本盘配置高。
2. 可习得声明：普世标准可以通过后天觉察和训练习得。
3. 收束语：真正的宝藏是你的内核，很多时候只是时间未到。
4. 预告（选填，有下一集时用）。

- 例子虚构：所有例子必须来自用户提供的真实素材。
