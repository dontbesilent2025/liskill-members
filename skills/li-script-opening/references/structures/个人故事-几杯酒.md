# 个人故事-几杯酒

## 基本信息

- 脚本类型：故事
- 难度：未标注
- 一句话适合：人生有 3 个以上明显节点（苦难、转折、成就）、情感积累足够深，想用举杯串联完整人生故事来建立 IP 人设的人。
- 必需素材：出身背景与最苦的画面、至少 3 个带具体细节的人生节点（含一个转折或成就）、每杯敬的对象、当下状态与感悟、末杯升华金句
- 呈现形式：口播
- 篇幅：500–900 字，约 1.5–3 分钟（参考系列为 500–1200 字、1.5–4 分钟）
- 来源：cq-个人故事-几杯酒；参考视频：「敬自己一杯酒」系列（15 篇原始文稿）

## 什么时候选

- 人生有 3 个以上真实节点（苦难／转折／成就），想用举杯串联一条完整的人生故事，情感积累足够深。
- 杯数按节点数量定，3–10 杯为宜；节点不够 3 个、或节点说不出具体细节时不要选，不要硬凑。
- 和「个人故事-敬自己」的区别：敬自己固定三杯、300–400 字，第三杯必须是最复杂的多重反转；几杯酒按节点数定杯数，走完「原生苦 → 出社会苦 → 转机 → 成就 → 感恩」整条人生弧线，最后一杯敬观众升华。
- 可敬的对象不限于自己：某个年龄或状态的自己、家人（妈／后妈／爷奶／老公／孩子）、恩人（老师／朋友／贵人）。

## 结构链

第一杯（直接切入最具代表性的经历）→ 第二杯 → …… → 第 N 杯（每杯一个人生节点）→ 末杯升华（敬观众／所有人＋金句）

## 需要的素材

| 素材 | 数量 | 来源 | 缺了怎么办 |
|---|---|---|---|
| 出身背景与最苦的画面 | 1 个 | 用户亲历 | 追问：你的原生家庭是什么情况？最苦的时候有没有一个具体的画面或者一件事？ |
| 出社会后最大的坎 | 1–2 个 | 用户亲历 | 追问：出社会之后遇到过最大的坎是什么？当时是怎么熬过来的？ |
| 贵人／重要的人 | 1–3 人 | 用户亲历 | 追问：你人生里有没有一个人对你影响特别大？他做了什么让你记住他？ |
| 成就节点（第一次赚钱、买房、还债、家人受益等） | 1 个以上 | 用户亲历 | 追问：你做到的让自己最骄傲的一件事是什么？ |
| 当下状态与感悟 | 1 条 | 用户亲历 | 追问：你现在是什么状态？对过去的自己最想说什么？ |
| 每个节点的细节（年龄、地点、数字、对话） | 每杯至少 1 个 | 用户亲历 | 追问：这个能说得再具体一点吗？当时是几岁、在哪、发生了什么？ |
| 末杯敬的对象与金句 | 1 句 | 用户亲历 | 占位：【待补：最后一杯敬谁＋一句金句或祝福】 |

## 开头规则

第一杯直接切入最具代表性的苦难或人物，不做铺垫。通常敬一个具体的「自己」（某个年龄、某件事的自己），或对人生影响最深的人。

句式：

- 「第一杯，敬<年龄>岁<做某事>的自己。」
- 「第一杯，敬我<家人或恩人>。」

## 信息点模板

每杯格式：「第 X 杯，敬<对象／年龄>」＋具体事件（带数字、场景或对话）。情感弧线：原生苦 → 出社会苦 → 转机 → 成就 → 感恩。

**第一杯**

1. 对象：人物、年龄或状态。
2. 核心事件：带细节数字或场景。

**第二杯**

3. 对象。
4. 核心事件：带细节或对话。

**第三杯至第 N 杯（按实际节点数继续，3–10 杯为宜）**

5. 对象。
6. 核心事件：带细节。

**末尾升华**

7. 敬对象：观众、粉丝、所有在苦难中没放弃的人。
8. 金句或祝福语。

## 拍摄提示

纯口播，或配举杯动作。拍之前对着镜子读一遍，有不顺口的地方改掉再拍。

## 常见错误

- 用抽象情绪代替具体事件：不能只说「很难」，要说「开了三年亏了三年，最后一年才回本」这种。
- 书面腔、AI 感、排比金句堆砌，嘴上说不顺。
- 为了凑杯数硬加节点，或某一杯没有任何数字、场景、对话。
- 情感弧线不完整，只有苦没有转机和感恩。
