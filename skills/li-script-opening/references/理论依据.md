# 理论依据

本文件由仓库的 methods 目录生成，请勿在技能目录里手改。用于理解李同学写稿方法背后的机制和适用边界；对话中不说理论名，只说人话。核实状态：基于已有知识，未在本轮外部核实；理论表述均为中文意译

## 开头：关联理论（主）＋信息缺口理论（辅）

- 关联理论（法国认知科学家斯珀伯与英国语言学家威尔逊，《关联：交际与认知》，1986）。意译：人会把注意力给「对自己有用、又容易理解」的信息。对应：开头里的说法、场景、问题决定了谁会觉得有关，也就决定了留下的是谁
- 信息缺口理论（美国行为经济学家乔治·勒文斯坦，《好奇心的心理学》，1994）。意译：人意识到自己知道的和想知道的之间有一个具体缺口时，会想补上。对应：用问题开头、信息点之间留悬念，观众会继续看
- 边界：身份能回答「和你有什么关系」时，可以放开头；专业账号不为关联牺牲准确

## 元素：框架语义学（主）＋认知负荷理论（辅）

- 框架语义学（美国语言学家查尔斯·菲尔墨，1982）。意译：一个词会唤起它所属的整个场景。对应：「别墅」「380 块」「放了一个星期」让观众自动补出人群和处境
- 认知负荷理论（澳大利亚教育心理学家约翰·斯威勒，1988）。意译：人一次能处理的新信息有限。对应：每句只叠 1–2 个元素；李同学「同一秒信息无限多」的说法要收窄
- 边界：元素必须是真实的；没人评论有多种原因，「没给评论缺口」只是创作者能控制的一个

## 四类脚本：使用与满足理论（主）

- 使用与满足理论（美国社会学家伊莱休·卡茨等，1973–1974）。意译：观众带着自己的需要主动挑内容：获取信息、确认身份、与人联结、消遣
- 情绪脚本辅助：社会认同理论（英国社会心理学家亨利·泰弗尔与约翰·特纳，1979）。意译：人通过所属群体确认「我是谁」。对应：帮谁说话、共同敌人
- 故事脚本辅助：叙事传输理论（美国心理学家梅兰妮·格林与蒂莫西·布洛克，2000）。意译：观众被故事带进去时会代入人物、降低反驳。对应：画面、阻碍、内心动荡、变化
- 过程脚本辅助：信号理论（美国经济学家迈克尔·斯宾塞，1973）。意译：对方看不见真实能力时，可见、难伪装的行动比自我声明更有说服力。对应：过程脚本是证明方式
- 边界：一条视频以一类为主，可以混合；干货的收获感必须建立在真实可用的方法上

## 真实感：拟剧论

- 拟剧论（美国社会学家欧文·戈夫曼，《日常生活中的自我呈现》，1959）。意译：观众会用细节检查前台表现和背后实际是否一致，一处不一致整体都会被怀疑
- 边界：li 技能只帮用户把真实发生的事讲得可信，不编造事件；「半真半假」不作为技能规则

## 评论缺口与做局：广告效果层级模型

- 广告效果层级模型（美国营销学者拉维奇与斯坦纳，1961）。意译：观众从看到到购买要经过几个阶段，每个阶段需要不同的信息。对应：预先想好观众在哪里会停、会质疑、会评论、会去验证
- 边界：只设计理由出现的位置，不伪造评论、不编造证据；设计痕迹被看穿会整体失去信任

## 信息密度与推进：信息缺口理论＋认知负荷理论

- 每次揭晓一部分、同时打开下一个缺口，观众会继续看；密度以听得懂为上限。李同学「每个信息点之间要有反转」收窄为「相邻信息点之间要有推进：转折、加码或揭晓」
