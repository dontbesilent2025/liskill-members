# 多视角找角度：调度协议

## 运行形态

主 Agent 负责保留输入内核、调度、检查连接和向用户展示地图。references/lenses.md 的每个启用视角是一项独立子 Agent 任务；当前 N 为 13（L01～L12 通用理论视角，L13 元素召人）。按运行环境的并发容量分波运行。以后理论库增减时，以启用视角数量作为 N，不把 13 写成永久上限。

有子 Agent 能力时（例如 Claude Code 的子 Agent 工具、Codex 的 spawn_agent），为每位成员新开一个不继承当前对话的任务，防止现有角度污染独立探索；向每位成员提供同一原素材、输入内核、注意力资产、事实边界与其专属理论规则。不要覆盖模型或推理强度。收集结果后，用户选定方向时再唤回相关成员深化。

本技能的全部判断规则来自自身 references/，运行时不调用其他技能或依赖本机私有知识库。

### 没有子 Agent 能力时

豆包、网页对话等不能启动子 Agent 的客户端，改为单 Agent 依次分析：开头明确告诉用户「这一轮由我一个人依次用 13 个视角分别分析，没有并行团队」；每个视角只按自己的机制和失效边界判断，写完一个再写下一个，不为了凑差异改写前面的结论。视角索引里注明「单 Agent 依次分析」。不得把这种结果说成团队成果。

单 Agent 时按下面做，避免回复过长、被截断或需要用户反复催：

1. **先各写各的**：逐个视角只按自己的机制写，不引用、不比较前面的视角。
2. **同一回复里写完**：每 3 个视角一个小标题（如「已返回 3/13」），最后一组 4 个，不中途停下等用户。
3. **视角状态写短**：每个视角 2–3 行，只写状态、一句话方向、连接编号，括号里写回到生意的归类（客户／准客户／同行／路人）；没有连接的写一句理由。示范、误用和理论解释都不写进回复。
4. **最后统一整理**：全部写完后，主 Agent 做一次合并：标出重合路径、撤回失真，再按「连接卡字段」把实质不同的连接各写一张完整卡片。完整字段只在这里出现一次。
5. **继续深化**：用户选定方向后，由主 Agent 按该视角的规则重新分析，不需要子 Agent。

能不能开子 Agent，和能不能写文件，是两件事：只是不能开子 Agent，就用上面的单 Agent 方式，照常写内容卡；只是不能写文件，就照常运行视角，结束时输出交接卡；两样都不能，两条都照做。


## 成员任务

每位成员只处理自己的理论机制，不看其他成员答案。成员要寻找“原素材通过这个理论与哪类人的什么现实处境发生关系”，不承担排名、选主角度或争点筛选。

任务中给出：

- 原文或用户指定的可读原件；
- 已确认事实、用户观点与未核实信息；
- 作者想保留的独特机制和原本受众；
- 对应视角的机制、连接动作与失效边界；
- 店的基本情况（卖什么、服务范围、主要客户），供写「回到生意」；
- references/connection-standard.md 的连接定义、references/business-check.md 及下列结果格式。

给成员的视角规则里可以附上该视角的「实体老板怎么用」示范，并提醒成员示范是编的，不能当素材事实。

成员先提交一条最有根据的连接。第二条只有在人群、场景、后果或机制不同的情况下提交；不能为增加数量换标题或抽象词。材料不适用时返回无连接。

### 成员结果格式

视角编号与理论：
状态：有依据的连接／待验证连接／仅有注意力素材／本视角未发现连接／失真
状态理由：

每条连接：

- 一句话方向：这份素材与谁的什么问题有关；
- 原素材锚点：保留哪项事实、观点、例子或一手结果；
- 先注意的理由：原素材何处产生真实的信息缺口或注意；
- 相关人群与场景：哪类人、在何时遇到；
- 共同后果或任务：影响其什么选择、利益、身份或关系；
- 理论机制：素材如何与这类人发生关系；
- 继续了解的价值：增加何种理解、判断或行动可能；
- 受众范围：专业小众／跨群体／广泛共同处境；
- 关切强度：弱／中／强，并说明依据；
- 尺度变化：抽象、人群、时间或价值中的哪一种，从何处移到何处；
- 证据上限与现实信号：直接材料能支持什么，当前人群关切是否有现实证据；
- 失真边界：竞争解释或失败条件，什么会让连接变弱或失真；
- 回到生意：客户／准客户／同行／路人，加一句连回路径或连不回的原因。

以上字段与 references/connection-standard.md「连接卡字段」一致，以那里为准。

成员不得把理论本身的研究结果当作本素材中的人群事实，也不得把用户口述数字当作已核实规模。

## 逐批展示

第一位成员带回有效或待验证连接后即可发送首批用户可见结果；后续每约 2～3 位成员返回或一波结束，再展示新增连接。每批写“已返回 X/N”，用普通话语说明原素材怎样连接到具体人群，标明证据边界与稳定编号，例如 L03-C1。仅有注意力素材、无连接和失真也计入已返回数。

用户中途补充事实或指出方向偏离时，暂停未分派的旧任务，更新共同素材包；必要时让受影响成员复核。已展示的连接若被推翻，明确标为修订或撤回。子 Agent 的内部逐字生成过程可能不可见；逐批展示指成员完成后及时报告，不声称直播隐藏思考。

## 主 Agent 的连接检查

使用 references/connection-standard.md 逐条检查资产保留、忠实性、真实性、可识别性、共同后果、信息增量和证据上限，并对照其中「实体店素材最常见的三种失真」。主 Agent 可以把证据状态降级，不能凭推理升级。「回到生意」只核对写得对不对（人群归类、地域、客单价、连回路径），不因为连不回就撤下连接。

比较两条候选时，看“人群＋场景＋后果＋机制”是否相同：

- 有实质差异：分别保留；
- 结果相近、理论机制不同：标明重合与不同解释，保留来源编号；
- 完全同义：合并表述，保留全部来源编号；
- 失真：不进入可选连接地图，在视角索引中说明撤回原因。

不要暗中只留下看似大众的方向。专业小众且关切很强的连接与广泛但证据弱的连接，应分别展示。多元性来自真实差异，不能靠每个理论硬凑一个新题。

## 最终交付

1. 简要恢复原素材的判断、事实边界和不可丢失的注意力资产。
2. 按人群或共同关切整理连接地图；每条保留稳定编号、原素材锚点、理论机制、受众范围、关切强度、证据状态、继续了解的价值和回到生意。
3. 附视角索引，列出全部 N 位成员贡献了哪条连接、哪里重合，或为何没有有效连接。没有有效连接的理论不应被主 Agent冒名补写。
4. 解释哪些方向有不同的人群、场景和后果；对可疑连接说明失真或待补证据。可以分组，不排序、不推荐主方向，也不把多个连接压成唯一大命题。
5. 让用户点名任何连接、拒绝某项理论解释或补充材料。用户主动选择后再深化。

不输出综合流量分数、最佳角度或发布决定。用户明确要求比较或推荐时，才在下一轮根据其目标进行判断。

## 长材料与跨轮对话

长录音、逐字稿或多文件输入先形成可回溯素材包；成员读取相同的用户指定原件或带来源定位的摘录。不能只传已含主 Agent 结论的摘要。

用户选择方向后更新原素材和连接卡；仅唤回相关成员继续细化，或在用户要求继续发散时运行其余理论。再次输出时保留原编号，交代保留、修订、撤回与新发现。
