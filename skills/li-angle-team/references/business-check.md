# 回到生意检查

本文件规定连接卡第 13 个字段「回到生意」怎么写。它来自李老师两条方法：

- **需求理论**：大流量来自比产品更大的用户需求，但内容主线必须能回到业务交付，让进来的人在过程中被营销掉。只拍产品需求太小；需求放大到和生意无关，召来的是泛流量。
- **元素吸引人群**：场景、道具、金额、身份、地域会筛选出「觉得这和我有关」的人。召来谁，取决于素材里放了什么。

两条合起来就是本检查要回答的问题：**这条连接召来的人，是不是老板的客户或准客户；如果是，怎样从这层关系连回生意。**

主理论：营销近视症（见 `references/theory-sources.md`）。

## 它在技能里的位置

- 这是一个**字段**，每条连接都写，供用户自己挑方向时参考；
- 它不参与排序，不用来删掉连接，也不替用户推荐。「连不回」的连接照样进入连接地图；
- 用户明确说「只看能带来客户的」时，才按这个字段帮用户筛，并说明筛掉了哪些；
- 账号是纯流量号、个人 IP 号、或者生意在线上全国卖时，按用户说的目标判断，不硬套实体店的标准。

## 先确定「生意」是什么

从内容卡卡头「账号定位」、素材和对话里取三件事：

1. 店卖什么、怎么交付（到店、上门、线上）；
2. 服务范围（城市、片区、服务半径）；
3. 主要客户是谁、大概什么消费水平。

缺的时候不发问卷：先按素材能推出的写，标「待确认」。例如「（待确认：不清楚上门服务覆盖哪些区）」。三件事都推不出时，在首批结果里问一句「你的店卖什么、主要做哪一片」。

## 怎么写

格式：`<人群归类>；<连回路径或连不回的原因>`

人群归类四选一：

| 归类 | 判断 |
| --- | --- |
| 客户 | 已经在买、或正处在购买场景里的人。例：给父母订生日宴的子女之于火锅店包间 |
| 准客户 | 现在不买，但处境会让他在可见的将来需要这项服务，且在服务范围内。例：刚收房的业主之于装修公司 |
| 同行 | 做同类生意的人。只有店里同时做培训、招学徒、卖设备或供货时才算连得回 |
| 路人 | 觉得有关、愿意看，但和这门生意没有购买关系 |

连回路径写一句：这层关系通过什么接回店里的哪项服务。例：「办聚会怕临时加人 → 上门烤羊可以现场加量」。

连不回时写原因，常见四种：

- **需求放太大**：一路抽象到「人生」「创业」「人性」，和店里的服务断了；
- **地域不符**：召来的人在服务范围外（例如主城的上门服务，召来了外地人）；
- **客单价不符**：元素召来的人消费水平和店里差太多；
- **只召来同行**：讲的是经营技巧或行业内幕，客户不关心，店里也不做同行生意。

## 判断时容易犯的错

- 把「很多人会看」当成「能连回生意」。受众范围大不代表召来的是客户；
- 把「回到生意」写成「结尾加一句来店里」。连回路径要在关系本身里，硬加的营销句不算；
- 为了让连接连得回，改写素材事实或补一个素材里没有的服务；
- 因为连不回就不展示。连不回是用户挑方向时的信息，用户可能就想做一条涨粉的内容。

## 示范

以下为示范，店和细节是为说明方法编的。

示范素材：重庆一家烤全羊上门服务，给江北一栋别墅的生日宴烤羊，开席前客户说多来了十几个人，老板临时加烤羊腿，把切羊搬到院子中间让客人围观。

| 连接 | 回到生意 |
| --- | --- |
| 办家庭聚会、生日宴的人最怕临时加人 | 准客户；办聚会怕临时加人 → 上门烤羊能现场加量 |
| 给公司张罗团建的行政，可以拿这段当方案 | 准客户；团建方案参考 → 公司包场服务 |
| 别的上门餐饮老板学怎么应对加人 | 同行；店里不做培训，连不回 |
| 「做生意要有格局，多来的人不加钱」 | 路人；需求放太大，召来的是想听创业道理的人 |

四条都进地图，用户自己挑。想要客户的人看前两条，想先涨粉的人也可能挑第四条，这时在第 4 步「值不值得拍」再判断。
