# 观点型-强观点钩子-三论点

## 基本信息

- 脚本类型：情绪
- 难度：3 级
- 一句话适合：手头有带具体数字的真实客户踩坑案例、能总结出赛道 3 个共性痛点，想在该赛道建立「踩坑顾问」人设的账号。
- 必需素材：一句「不要做 X」强观点、一个真实客户案例（背景＋成就＋转折＋代价数字）、3 组论点（强观点＋痛点场景＋对比＋共鸣情绪）、服务数字、一句给入行者的忠告
- 呈现形式：口播
- 篇幅：600–700 字，平均每 4–5 秒一个信息点；参考视频 681 字，约 1 分 47 秒
- 来源：cq-观点型-强观点钩子-三论点；参考视频：抖音 @老徐谈农场「普通人别回农村创业！」（2026.06）

## 什么时候选

- 有一个强观点（「千万不要做 X」），并且有一个真实客户案例能坐实它：人物背景、原来的成就、转折、具体赔了多少都说得出数字。
- 能从自己服务的赛道里总结出 3 个共性坑，每个坑都有具体场景，信息密度高、代入感强。
- 想建立「踩坑顾问」型人设，结尾用服务经验建立信任、带出成交。
- 没有真实案例不要选，这条做不了。手上是身边人物有起伏的完整故事、而不是客户踩坑数字时，改选「观点型-案例故事递进」；只有日常观察、没有案例时，改选「观点型-错误对比-三举例」。

## 结构链

强观点钩子 → 案例主角（背景＋成就）→ 转折与代价 → 引入好奇 → 论点 1 → 论点 2 → 论点 3 → 成交理由 → 为客户着想 → 金句升华

## 开头规则

开头要用「强观点＋真实案例＋负面堆叠」拉住人：一句反常识的强观点，紧接案例人物的背景、成就数字、转折和具体代价，最后引入好奇，让观众想听后面的几件事。开头要能刺激目标用户的情绪波动，够狠。

句式：

- 「千万不要<做某事>，除非你像他一样，<极端条件>。」
- 「我一个客户在<地方>做<行业>，赚了<数字>；他<转去做某事><年数>，不仅赔了<数字>，还<身体或精神代价>。」
- 「上个月我跟他聊天，他给我讲了<N>件事。」

## 信息点模板

**强观点开篇**

1. 强观点钩子：一句话，不要做 X。
2. 案例主角＋背景＋成就：他是谁，原来有多好，具体数字。
3. 案例转折＋代价：赔了多少，具体数字。
4. 其他代价：身体或精神，越具体越好。
5. 引入好奇：他给我讲了 N 件事……

**论点 1**

6. 强观点：这个赛道某个核心问题，一句话结论。
7. 痛点场景：具体描述这个问题怎么体现在日常里。
8. 强对比：和之前、和城市或和预期的对比。
9. 共鸣情绪：那种感受用一句话说出来。

**论点 2**

10. 强观点。
11. 痛点场景。
12. 强对比。
13. 共鸣情绪。

**论点 3**

14. 强观点。
15. 痛点场景。
16. 强对比。
17. 共鸣情绪。

**成交收尾**

18. 成交理由：我服务过多少人、多少年，这类问题有多普遍。
19. 为客户着想：表面看起来怎样，但真相是……，建议慎重。
20. 金句升华：一句话呼应开头。

## 常见错误

- 案例没有具体数字（成就、赔了多少），开头不够狠，刺激不到目标用户的情绪。
- 论点只有结论，缺痛点场景和对比；每个论点都要走完「强观点 → 痛点场景 → 强对比 → 共鸣情绪」。
- 没有真实案例硬做这个结构。
- 收尾缺少服务数字，成交理由立不住。
