# B2B型-工厂参观

## 基本信息

- 脚本类型：过程
- 难度：2 级
- 一句话适合：有自己工厂或合作工厂、想吸引 B 端采购客户的账号，用「带大家参观工厂」展示规模、生产流程和品控能力。
- 必需素材：行业地域与身份、厂区规模、工艺流程、3–5 个核心设备或工序、质检做法、结尾关注理由
- 呈现形式：跟拍
- 篇幅：未标注
- 来源：cq-B2B型-工厂参观；参考视频：抖音【鹏泰木业建筑模板】「大家好，我是蔡榕，带大家参观下鹏泰木业」

## 什么时候选

- 有工厂或合作工厂，能实地边走边拍，想展示规模和专业性。
- 目标观众是同行业的 B 端采购客户，要让他们看到你的规模和品控能力。
- 难度低，有实际工厂、按模板就能填；没有可拍摄的真实工厂时不要选，内容全部依赖真实工厂数据。

## 结构链

自我介绍 → 厂区整体规模 → 工艺流程概述 → 生产工序细节×N → 质检／品控 → 结尾关注理由

## 开头规则

开头用一句自我介绍交代「行业＋地域＋身份＋目的（带大家参观）」，让采购客户立刻知道你是谁、要看什么。

- 「大家好，我是<名字>，带大家参观下<工厂名>。」
- 「我是<地域>做<行业>的<名字>，今天带大家看看我们的工厂。」

## 信息点模板

全程实拍边走边说，按参观路线顺序排列：每个信息点为【口播】，画面拍对应区域或设备。

**自我介绍**

1. 【口播】行业＋地域＋身份＋带大家参观的目的。

**厂区整体规模**

2. 【口播】厂区规模数字：占地面积＋各区域分布。

**工艺流程概述**

3. 【口播】从原材料到成品的一体化流程，一句话说完。

**生产工序细节×N**

4. 【口播】设备 1：名称＋作用＋生产能力。
5. 【口播】设备 2：名称＋作用。
6. 【口播】生产规模：流水线数／员工数。
7. 【口播】设备 3 或下一道工序。

**质检／品控**

8. 【口播】质检流程：人工检查＋品控细节＋降低次品率的做法。
9. 【口播】成品规格／出货。

**结尾关注理由**

10. 【口播】关注理由：继续分享创业历程／工作日常，或给出行动指令。

## 拍摄提示

- 实拍，边走边说，口播配合实地拍摄画面。
- 脚本按参观路线顺序排列：厂区整体 → 各区域 → 生产车间各设备 → 质检 → 成品出货。
- 讲到每台设备时画面对准该设备，配合说出名称、作用和规模。

## 常见错误

- 开头没有交代行业、地域和身份，直接拍车间，采购客户不知道这是谁家工厂。
- 工序只拍画面不说数字，缺少设备数量、生产速度、流水线数这类能体现规模的信息。
- 漏掉质检／品控段，无法回应「让采购商看到你的品控能力」这一核心。
