# 结构索引

由仓库的结构库真源生成，请勿手改。按李同学的四类脚本分组：干货给收获感，过程留住时间、证明能力，故事建立人设和代入，情绪帮目标用户说话。第 6 步先定脚本类型，再在这一组里挑 2–3 个候选；完整结构在本技能的 references/structures 目录，文件名就是结构名。

共 25 个结构，另有 2 种形式已有独立技能。
