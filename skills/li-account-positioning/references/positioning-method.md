# 李同学定位方法：依据、例子与判断细则

本文件是 `li-account-positioning` 的随包参考。方法主干来自李同学线下课录音转写（2026-05-29 第一天上午、2026-06-02 第二天下午）和方法论校准稿（02 变现逻辑、03 定位方法论、04 IP 与人设、15 元素吸引人群、19 账号训练、31 平台与渠道判断）。理论依据和边界见 `references/theory-grounding.md`。

## 一、李同学的原话依据（转述，括号内为录音时间）

### 定位

| 方法要点 | 李同学怎么说 |
|---|---|
| 职业不是定位 | 「我是做火锅的」「我是律师」只是告诉别人你是谁。（第一天上午 18:37 前后） |
| 定位的本质 | 定位是商业定位，不只是短视频定位：从竞争对手出发，在用户的眼中寻找优势的位置；最重要的词是「竞争对手」。（20:32–21:34） |
| 定位的目的 | 对抗内卷。做的人多了才需要定位；五年前「做短视频这件事本身就是一种定位」。（19:10–19:56） |
| 本地门店 | 当地正经好好做短视频的人不多，做短视频这件事本身就是差异化。（35:34） |
| 拆成小定位 | 变现定位、价值定位、用户定位、人设定位、形式、风格……「不止这六个」。（19:56） |
| 最好的方法 | 做定位最好的方式就是寻找空位。（25:02） |
| 区域空位 | 回重庆前调研：重庆、四川、贵州、广西、广东都没有同类知识博主，「回来的时候无一个竞争对手」。（23:31–26:22） |
| 行业空位 | 90 后律师：律师太卷 → 离婚、刑法也卷 → 切「专打网络电商官司的律师」，因为他懂、没人做。（27:08–29:21） |
| 切细不怕少 | 担心切细客户变少：抖音上「再小的群体都是很大的群体」。（37:23–38:52） |
| 跨界融合 | 跨界融合这个方法来自自己的经历，「是我做成功过」。（2:23:10） |
| 用户最重要 | 「最重要的我认为是用户定位和用户思维」，不要自嗨（兔子用胡萝卜钓鱼）。（1:54:12） |
| 列人群的问法 | 同一价值可以给不同的人；让 AI 按不同领域、不同经济和收入水平列 10 个人群。（2:21:59） |
| 不必定好再开始 | 定位重要，但不是一下就能获得的，在走的路程中不断发现；产品由真实流量反推。（34:34–35:17） |
| 不离开本行 | 做建筑 13 年就拍建筑；「不要抛弃你本行业，在你本行业去找到更好的你」；不知道怎么定位，先用「创作灵感」找行业话题和用户，看同行的变现定位。（第二天下午 53:26–54:17） |

### 变现

| 方法要点 | 李同学怎么说 |
|---|---|
| 目的 | 做短视频的目的就是变现；但「做 IP 不要做一个满眼都是钱的人」。（36:02、34:52） |
| 流量不等于变现 | 三条视频：播放最高的那条咨询为 0，播放低的两条咨询 180、126。流量像店门口走过 1000 人，不一定进店，进店不一定买。（43:24–44:27） |
| 复盘看咨询 | 短视频复盘要看的是每天的咨询和变现有多少，流量没有那么重要。（44:27） |
| 变现公式 | 每条视频目的不同，合在一起才变现；「变现的核心是什么？流量加需求加信任就可以得到转换」。（47:36） |
| 信任的本质 | 信任来自了解和熟悉；所以多数 IP 账号第一条置顶是个人故事，让人了解你的过去。（48:45–49:33） |
| 一条扛不了全部 | 没有一条视频能同时有流量、能成交、还能建立人设。（50:18） |
| 卖的是人 | 楼下卖腊肉卖的是产品，抖音上卖的是人和故事；产品满足需求，人物制造品牌。（55:26–57:13） |
| 非标品要信任 | 理发、餐饮、课程、心理咨询这类非标化产品「更需要 IP 和信任」，没有就很难转化。（59:42–1:00:02） |
| 三类顾客 | 有需求还着急（约 10%）、有需求不着急、有潜在需求自己不知道；90% 的人在抢那 10%。（2:02:08–2:03:44） |
| 急需的人怎么接 | 着急的人比价格、主动搜索，要用成交链条更短、价格有竞争力的方式接。（2:08:45–2:09:18） |
| 养后两类 | 不急的人要慢慢养；他自己刷某手表博主半年，有一天突然决定，第二天就去外地买了。（2:05:55–2:07:55） |
| 产品反推 | 流量来了有咨询，咨询多了有线上课，线上课看完率低有线下课，再有陪跑。（校准稿 02） |
| 教同行 | 很多学员做了 IP 后开始教学员，因为是纯利润；烤全羊学员开店后招学徒收费。（1:05:07–1:06:42） |

### 人设与账号门面

| 方法要点 | 李同学怎么说 |
|---|---|
| 人设是什么 | 你是谁，你要做什么样的人生，你代表什么价值观；不做「旅游博主」，做一个喜欢旅游、向往自由的人。（校准稿 04） |
| 靠事件打出来 | 真诚不好体现，「我们从事儿上见」；不要讲你真诚，用事来体现。（52:00） |
| 要真 | 流量可以没有，但不能骗；可以塑造、可以夸大，要是真实的自己。（58:54） |
| 多维 | 人设立体，不全是优点，有缺点和真实感；内容从你的故事、性格、专业几个维度挖。（51:40；校准稿 04） |
| 朋友和敌人 | 支持什么不一定有人设，反对什么更容易立住；知道帮谁说话、谁是对立面；和事佬很难有真朋友。（校准稿 04） |
| 置顶三条 | 第一条个人故事，第二条产品、团队或公司介绍，第三条点赞最多、评论区没人骂的那条。（1:01:39–1:02:33） |
| 头像与背景图 | 用生活照，笑、近距离；背景图是广告位，可以放门店、团队、讲课现场，不要全是营销。（1:03:41–1:10:42） |
| 昵称 | 一定有自己的名字，加上行业；门店可以带店名，但不能只有店名。（1:07:30） |
| 一句重复的话 | 在视频里植入一句话无限重复，靠重复让人记住。（1:08:10） |

### 元素、账号训练与平台

| 方法要点 | 李同学怎么说 |
|---|---|
| 元素筛人 | 什么元素吸引什么人：农村自建房烤羊吸引自建房客户，别墅烤羊吸引别墅客户，重庆街头吸引本地生活。场景、台词、道具都是筛选用户的工具。（校准稿 15） |
| 需求做大 | 本地商家只拍产品需求太小；暂时忘记产品，找比产品更大的需求，过程主线仍回到业务。（全量整理第十四节） |
| 数量目标 | 新号不定结果目标，定数量目标：没有数量就没有感知，没有感知就无法迭代。（校准稿 19） |
| 节奏 | 基础两天一条，更好一天一条；做 60 条不火的准备。（校准稿 19） |
| 周期 | 任何账号都有周期；一个系列能跑两年已经很厉害；跑通后还要试更多系列。（校准稿 19） |
| 平台难度 | 抖音内容难度最高；抖音火的内容到视频号、小红书相对容易，反过来不一定。（1:50:10–1:51:14） |
| 视频号 | 视频号获客很强，用户年龄偏大；视频号直播预约提醒比抖音强得多。（1:51:33；第二天下午） |
| 同发 | 同一作品发抖音、视频号、小红书都可以，不违规。（第一天上午） |
| 不固守 | 以前看不上视频号和小红书，跨平台带来意外增长；平台不是本质，获取流量和转化的能力才是本质。（校准稿 31） |

## 二、六类空位：实体店例子

例子只用来帮助理解方向，不能直接套给用户；候选必须用用户自己的经历和资源。

| 方向 | 李同学的案例 | 实体店怎么用（示意） |
|---|---|---|
| 区域空位 | 回重庆做西南第一个短视频知识博主 | 某个区、镇、商圈里第一个老板天天出镜的装修公司 |
| 行业细分 | 律师 → 网络电商法律师 | 装修 → 只做「老房局部翻新」；美业 → 只做「产后修复」 |
| 人群空位 | 服务女强人、美业老板、实体老板 | 火锅店只拍「带爸妈来吃」的家庭客；美甲店只做上班族通勤款 |
| 形式空位 | 同样的知识，用更像用户世界的方式讲 | 同行都拍菜品特写，他拍后厨凌晨备料的全过程 |
| 身份空位 | 「律师」变成「小邱」，内容不变，接受度完全不同 | 「装修公司老板」变成「替业主盯工地的老师傅」——必须是他本来就在做的事 |
| 跨界融合 | 李同学自己的行业经验 + 重庆本地 | 做过 10 年厨师的美业老板；当过监理的装修老板 |

## 三、判断细则

### 三条件：空位 = 有人要 × 没人占 × 我占得住

- **有人要**：没人做，可能只是因为没人要。检查方法：目标用户会不会搜这个词、问这个问题、为这个差异多走两公里，付不付得起这个价？律师案例成立，一部分原因是电商纠纷真有人要、愿意付钱。
- **没人占**：比的是用户脑子里有没有现成的第一名，不是全网有没有人做。实体店的对手是用户刷到你时能随手换掉你的那几家：同城、同品类、同价位。
- **我占得住**：差异必须来自真实的经历、手艺、资源、时间。编出来的身份撑不过 60 条；需要老板天天做到他做不到的事，也撑不住。

### 变现链路

李同学的「流量 + 需求 + 信任」在本技能里拆成三问：

1. **流量**——靠什么让人刷到。只拍产品的视频，需求只覆盖着急要买的那 10%；要把需求做大（聚会、搬家、怕被坑、带爸妈），主线再回到业务。
2. **需求**——刷到的人里有没有要买的。元素决定来的是谁（见下文）。
3. **信任**——他凭什么选你。信任来自了解和熟悉，所以要人出镜、讲个人故事、拍过程和真实事件。

**客单价和信任深浅**：以下是本技能根据李同学「非标化更需要 IP 和信任」和他的买表经历做的推论，用来决定人设和成交路径的分量，不是李同学的原话：

- 顾客买前就能判断好坏（标准品、低客单）→ 看价格和图就能下单，成交路径短，团购和价格是主力。
- 买过才知道（非标品）→ 要信这个人，老板出镜、人设和个人故事优先。
- 买完也难判断、出错代价大、客单高（装修、医美、婚庆）→ 要很深的信任，决策周期长，成交路径里要留私信和咨询，过程和案例要拍很多条。

**三类顾客对应的打法**：

| 顾客 | 占比（李同学估） | 怎么接 | 对应议程目的 |
|---|---|---|---|
| 有需求还着急 | 约 10% | 价格、团购、搜索词、成交链条短 | 成交 |
| 有需求不着急 | 多数 | 干货、避坑，慢慢养 | 信任 |
| 有潜在需求 | 多数 | 人性、冲突、故事、过程，把需求做大 | 引流 |

### 人设

- 人设写成价值观（「一个……的人」），职业名只是起点。
- 帮谁说话 = 目标用户；反对什么 = 让目标用户吃亏的做法。只反对做法，不点名同行或个人，避免纠纷。
- 人设要能被事件证明：一件真事、一个具体动作、观众自己得出结论。删掉形容词后看不出，事件就不够。
- 要有一面真实的缺点或习惯；全是优点的人反而不可信。
- 可以塑造和放大，不能编。编出来的事撑不过一批作品，也违反「我占得住」。

### 元素

- 元素有五类：身份、场景、地域、金额、道具与台词。每一个都在回答观众心里的问题：「这是不是说给我的？」
- 金额要和客单价对上。金额远高于客单价，会引来看热闹的人；远低于，会引来只比价的人。
- 想要更大的流量，可以在场景和需求上做大，金额和主线仍要回到自己的生意。
- 不要窄到只剩一个人能代入：抖音上小群体也是大群体，但窄到连目标用户本人都不在其中就过头了。

## 四、常见误用

- 把九个小定位全部填满当成定位完成 → 只留一个主空位。
- 「同城没人做」靠想象 → 必须让用户查，否则标【待查】。
- 为了差异编一个身份或经历 → 违反「我占得住」。
- 劝老板换行业、做和本行无关的泛娱乐号 → 违反「在本行业找到更好的你」。像房地产老板拍情感号，流量有了也变不了现。
- 只问播放量，不问咨询 → 复盘看咨询和来的是谁。
- 一条视频想同时扛流量、成交、人设 → 分给 3 个议程，各有目的。
- 人设靠自夸（「我很专业」）→ 换成一件真事。
- 没到 30 条就因为没流量推翻定位、或换平台 → 先攒够样本再复盘。
- 把定位当成定死的结论 → 交付时必须写复盘节点和调整规则。
