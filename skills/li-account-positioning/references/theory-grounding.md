# 账号定位的理论依据与边界

本文件是 `li-account-positioning` 的随包参考。李同学的方法是主干，理论只用来解释机制、划边界。每组只保留一个主理论；辅助理论只在它能解释主理论解释不了的机制时保留。

核实状态：以下理论内容均基于已有知识，未在本轮外部核实；理论表述都是中文意译，不是原文逐字翻译。对用户说话时不说理论名，只说人话。

## 一、总体判断

| 李同学的命题 | 审查状态 | 修正后的标准 |
|---|---|---|
| 职业不是定位，要找空位 | 保留 | 在同一批用户会拿来比较的对手里，占一个能区分、能记住、能用来选你的位置 |
| 不卷就不需要定位 | 收窄 | 竞争少时差异可以粗；变现、用户、信任任何时候都要有 |
| 找空位 | 收窄 | 空位要同时满足有人要、没人占、我占得住 |
| 变现 = 流量 + 需求 + 信任 | 保留，补条件 | 信任要多深，取决于顾客买前能否判断好坏 |
| 人设靠事件打出来 | 保留 | 观众更相信从行为里自己看出来的东西，较少相信自我介绍 |
| 什么元素吸引什么人 | 收窄 | 元素让观众判断「是不是我这类人的事」；元素要和客单价、目标用户对上 |
| 先定数量，做 60 条不火的准备 | 收窄 | 数量是为了攒够反馈样本、看出模式，需配合复盘，单纯堆数量不算 |
| 定位在走的路上发现 | 保留 | 交付暂定定位 + 验证信号 + 复盘节点 |
| 平台不是本质 | 保留，不补理论 | 作为执行判断写进技能，不需要理论支撑 |

## 二、理论选择说明

入选标准：能解释案例的主要机制，并且会改变技能里的某个判断步骤或边界。淘汰了几类：李普曼「拟态环境」和定位理论解释同一机制（用户脑中的简化分类），保留后者；波特竞争战略讲企业层面的成本与差异化，解释不了「用户脑中的位置」；麦克卢汉媒介理论、德鲁克渠道观点放在平台判断上只能得出「平台会影响表达」这类常识，删去；刻意练习、操作性条件反射解释的是创作者手艺怎么练，账号定位这一步关心的是定位要不要改，用涌现战略已经覆盖，删去；选择性注意和社会分类都能解释元素筛人，社会分类直接解释「是不是我」的判断，保留它。

## 三、理论锚点

### 1．定位理论（主理论：找空位、一句话定位）

- 人物：美国营销战略家艾·里斯（Al Ries）、杰克·特劳特（Jack Trout）
- 出处：《定位》，1981
- 理论原义（意译）：竞争发生在顾客的心智里。心智会给同类事物排座次，后来者很难在同一类别里挤掉第一名；更好的办法是找到心智中还没被占的位置，或者重新划一个类别，让自己成为这个类别的第一。
- 在技能里解释：为什么「我是火锅店老板」不算定位（职业只是类别名，报类别等于排队）；为什么要找空位、重新切类别（律师 → 网络电商法律师）；为什么「没人占」比的是用户脑子里的第一名。
- 边界：前提是用户会想到这个类别。没有需求的空位不成立，所以技能加了「有人要」。反例：同城唯一的分子料理火锅，没人做，也没人想吃。

### 2．议程设置（辅助：账号议程）

- 人物：美国传播学者马克斯韦尔·麦库姆斯（Maxwell McCombs）、唐纳德·肖（Donald Shaw）
- 出处：〈大众媒介的议程设置功能〉，《舆论季刊》，1972
- 理论原义（意译）：媒介未必能决定人们怎么想，但会明显影响人们想什么；媒介反复强调的议题会成为受众眼中重要的议题。后续的属性议程设置研究指出，反复强调一个对象的某些属性，这些属性会成为受众对它的印象。
- 主理论解释不了的部分：定位理论出自广告时代，默认靠一句口号占位。短视频账号没有口号位，用户对你的分类是被你反复讲的事塑造的。
- 在技能里解释：为什么定位要落成 3 个反复讲的账号议程，为什么前 30 条不追热点跑题，为什么差异词要反复出现。
- 边界：原研究对象是大众媒介，用在单个账号上是类比，不推出「讲得越多越好」。

### 3．涌现战略（辅助：暂定定位、账号训练与验证）

- 人物：加拿大管理学者亨利·明茨伯格（Henry Mintzberg）
- 出处：明茨伯格与沃特斯，〈论战略：深思熟虑的与涌现的〉，《战略管理杂志》，1985
- 理论原义（意译）：真正实现的战略，一部分来自事先的计划，一部分是在一连串行动中逐渐浮现、事后才被认出来的模式。纯计划和纯涌现都很少见，有效的做法通常是先给方向，再从实际反馈里修正。
- 主理论解释不了的部分：里斯和特劳特的定位是事前设计的；李同学强调定位「在走的路上发现」、产品由流量反推。
- 在技能里解释：为什么交付的是暂定定位；为什么李同学要先定数量目标（模式只有在足够多的行动之后才看得出来）；为什么第 30、60 条复盘、按信号调整，每次只改一项。
- 边界：涌现不等于随便拍。没有暂定方向和固定议程，反馈就没有可比较的对象。

### 4．搜索品、经验品与信任品（主理论：变现链路的信任深浅）

- 人物：美国经济学家菲利普·纳尔逊（Phillip Nelson）提出搜索品与经验品的区分；经济学家迈克尔·达比（Michael Darby）与艾迪·卡尼（Edi Karni）补充了信任品
- 出处：纳尔逊，〈信息与消费者行为〉，《政治经济学杂志》，1970；达比与卡尼，〈自由竞争与欺诈的最优数量〉，《法与经济学杂志》，1973
- 理论原义（意译）：有些商品买前看一眼就能判断好坏（搜索品）；有些要用过才知道（经验品）；还有些用过之后也很难判断，只能相信卖方（信任品）。越往后，顾客越依赖卖方的声誉和可信度，卖方也越有机会欺骗，所以信任越值钱。
- 在技能里解释：李同学说「非标化的产品更需要 IP 和信任」——理发、私房菜是经验品，装修隐蔽工程、医美接近信任品，所以要老板出镜、拍过程、讲真事；奶茶、洗车接近搜索品，价格和团购更管用。技能据此把「信任要多深」分成三档，决定人设和成交路径的分量。
- 边界：分类是连续的，同一家店的不同项目可能落在不同档；客单价高不一定就是信任品（品牌标准品可以很贵）。反例：一家连锁标准化快餐店，客单低、品质稳定，老板人设做得再强，对成交的帮助也有限。

### 5．拟社会互动（辅助：信任为什么要落在一个具体的人身上）

- 人物：美国学者唐纳德·霍顿（Donald Horton）、理查德·沃尔（R. Richard Wohl）
- 出处：〈大众传播与拟社会互动〉，《精神病学》，1956
- 理论原义（意译）：观众会和反复出现在媒介上的人物形成一种类似熟人的单向关系，觉得「我认识他」，并据此产生亲近和信任，哪怕对方并不认识自己。
- 主理论解释不了的部分：纳尔逊的分类说明了为什么需要信任，没说明短视频怎么产生信任。李同学说「信任的本质是了解、熟悉」，手表博主刷半年就让他直接下单，这是反复见到同一个人形成的熟人感。
- 在技能里解释：为什么昵称要有本人名字、头像用生活照、置顶第一条是个人故事；为什么人设要出镜的老板本人来承担，店名承担不了；为什么不急的顾客要「养」。
- 边界：熟人感需要同一个人持续出现，频繁换出镜人或只拍产品就形成不了；它解释信任的来源，不保证信任一定转成购买。

### 6．印象管理（主理论：人设靠事件体现）

- 人物：加拿大裔美国社会学家欧文·戈夫曼（Erving Goffman）
- 出处：《日常生活中的自我呈现》，1959
- 理论原义（意译）：人在他人面前的表现会影响别人对自己的印象。表达有两种：一种是有意说出来的（例如自我介绍），一种是从行为里不经意流露出来的。观众知道前者容易控制，所以更倾向于用后者去检验前者。
- 在技能里解释：为什么李同学说「真诚不好体现，我们从事儿上见」；为什么人设事件卡要写一个能拍出来的动作，并禁止「我很专业」这类自夸；为什么删掉形容词后还要能看出人设；为什么人设要真，演出来的东西经不起一批作品的检验。
- 边界：戈夫曼讲的是面对面互动，短视频是剪辑过的表演，观众也知道有设计。所以事件要具体、可信，不能太完美；人设要留一面缺点。

### 7．社会分类（主理论：元素吸引人群）

- 人物：英国社会心理学家亨利·塔吉费尔（Henri Tajfel）
- 出处：塔吉费尔关于社会分类与群际关系的研究，1970 年代；与特纳（John Turner）合作的社会认同理论，1979
- 理论原义（意译）：人会很快把自己和他人归入类别，并对「和我同类」的人和事更关注、更亲近。
- 在技能里解释：为什么自建房烤羊吸引自建房客户、别墅烤羊吸引别墅客户——场景、身份、地域、金额都是归类线索，观众一眼判断「这是不是我这类人的事」；为什么元素要和目标用户、客单价对上；为什么身份空位（「律师」变「小邱」）会改变接受度：观众把他从「专家」那一类换到了「身边的人」那一类。
- 边界：线索太窄会让目标用户之外的人全部划走，流量池变小；分类只决定谁停下来，留不留得住还要看内容本身。
