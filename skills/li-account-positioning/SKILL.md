# 账号定位（第 1 步）

李同学讲定位，第一句话是：「我是火锅店老板」只是职业，算不上定位。定位要**从竞争对手出发，在用户眼中找一个优势位置**；最好的办法是**找空位**。他同时说，做抖音的目的就是变现，可「变现的核心从来都不是流量」，要靠「流量加需求加信任」才能转化。

本技能带一个实体老板（餐饮、美业、装修、门店服务等）从零走完这件事，交付一个**可以马上开拍的暂定定位**：先算清钱从哪来，再找空位，再定人设和吸引谁的元素，最后给出前 60 条怎么拍、看什么信号、什么时候改。李同学同样强调定位要「在走的路上不断发现」，所以交付物里一定带验证信号和复盘节点。

## 随包材料

- `references/positioning-method.md`：李同学原话依据（定位、变现、人设、元素、账号训练、平台），六类空位的实体店例子，三条件、变现链路、人设和元素的判断细则，常见误用。第三步开始前读一次；用户问「为什么这么定」时据此解释。
- `references/demo-cases.md`：两个完整示范（社区火锅店、老房翻新装修），从第一步走到验证节点。用户卡住、要看「做完长什么样」时读；示范是虚构的，只能参考写法，不能把示范里的经历、数字套给用户。
- `references/theory-grounding.md`：每一步背后的理论、它解释什么、在哪里失效。对话中不说理论名，只说人话；用户追问依据或你要判断边界时读。

## 对话原则

1. **每次只问一个问题**；用户一次说了很多，就直接用，不再重复问。
2. **到判断点必须停下**，给选项和推荐顺序，由用户选：目标用户、主空位、人设、最终一句话。
3. **不编对手情况和用户的事**。「同城没人做」只能来自用户查过或亲口说的事实；没查过时写【待查】，并告诉他怎么查。人设事件、客单价、成交数字只能来自用户，缺了写【待补】。
4. **不劝人离开本行业**。李同学原话：「不要抛弃你本行业，在你本行业去找到更好的你。」空位和人设都从他真实的经历、手艺、资源里找。
5. **不追求九格填满**。变现、价值、用户、人设、形式、风格、区域、细分、跨界九个小定位分三层用：先定底座，再找一个主空位，最后定表达。
6. **不承诺播放量、粉丝数和获客数**。验证节点只说看什么、怎么改。
7. **用户说「先给我结果」「别问了」时**：立即停止追问，用已有信息补齐，所有推测的部分标【待确认】，直接进入第七步交付。交付即视为用户接受这份暂定定位：照常更新内容卡、输出结尾，一句话定位后加「（暂定）」。流程必须能走完。

## 固定流程

### 第一步：了解这家店

开场只问一句：

> 先介绍一下你的生意：做什么的、店在哪个区或商圈、做了几年、现在主要靠什么赚钱、一单大概多少钱、有没有已经在发的抖音号？想到哪说到哪。

从回答里提取：行业与品类、位置与服务半径、从业年限、现有变现方式、客单价、老板本人的经历和特长、现有账号情况。缺的关键项最多追问 2 个，一次一个。

**近邻转出**：用户已经发了 20 条以上、想知道账号为什么不涨或印象散不散——这是检查已有内容，告诉他用 `li-agenda-setting`（议程设置内容定位）更合适；他坚持要重新定位时，再继续本流程。

### 第二步：要不要细定位

李同学：定位的目的是**对抗内卷**——做的人多了才需要细定位；当地正经做短视频的门店不多时，「做短视频这件事本身就是差异化」。

让用户自己查一次（一次一个问题）：

> 打开抖音，搜「<区域>+<品类>」（例如「沙坪坝 火锅」），再点进「创作灵感」看看这个品类的热门话题。同城有几个**真人老板出镜、一周至少更新 2 条**的同行号？他们主要靠什么变现（团购、私信、直播）？

| 用户回答 | 判断 | 后面怎么走 |
|---|---|---|
| 0～2 个 | 竞争少，**粗定位**即可开拍 | 第四步只找 1 个最顺手的空位，不深挖 |
| 3 个以上，或用户说「很卷」 | 需要**细定位** | 第四步完整找空位 |
| 没查、不想查 | 按「需要细定位」处理，对手情况标【待查】 | 交付时把「查同城对手」写进验证清单 |

竞争少也要定底座。没人卷可以不找差异，但「靠什么赚钱、要谁来、凭什么信你」任何时候都要有。

### 第三步：底座——变现链路、用户、价值

先读 `references/positioning-method.md` 的「变现链路」一节。按顺序，每项先由你根据已知信息给推荐，再让用户确认或改。

**1. 变现定位：钱从哪条路进来**

依次定四件事，每件一句话：

| 项 | 问什么 | 规则 |
|---|---|---|
| 主变现 | 到店消费／团购核销／预约咨询到店／上门服务／加盟招商／线上卖货／教同行 | 只选一个主变现，其他写成「以后可能」。产品由真实流量和需求反推，不必一开始设计新产品；但现在主要靠什么赚钱必须说清 |
| 客单价 | 一单大概多少钱？顾客多久来一次？ | 只用用户给的数字，没给写【待补】 |
| 成交路径 | 顾客从刷到你到付钱，中间经过哪几步？ | 写成一条链：刷到什么内容 → 进主页看什么 → 怎么联系（团购、私信、电话、到店）→ 在哪付钱 |
| 信任要多深 | 顾客买之前能不能自己判断好坏？ | 见下表 |

信任深浅的判断：

| 情况 | 判断 | 对定位的影响 |
|---|---|---|
| 标准品、低客单（奶茶、快餐、洗车），顾客看图看价格就能决定 | 信任要求低，成交路径短 | 内容重价格、现场和团购，人设可以轻 |
| 非标品，买过才知道好坏（理发、美甲、私房菜、摄影） | 要信这个人 | 老板必须出镜，人设和个人故事优先 |
| 买完也很难判断、出错代价大、客单高（装修、医美、婚庆、学校培训） | 要很深的信任，决策周期长 | 人设、过程和案例要撑很多条，成交路径里留私信／咨询环节 |

李同学的依据：「非标化的产品更需要 IP 和信任」；用户点赞可能因为你专业，下单往往因为喜欢、信任或被打动。

**流量 + 需求 + 信任三查**：主变现定完，对照这条链各问一句，答不上来的写进【待确认】：

- **流量**：这个号靠什么让人刷到？只拍产品，需求太小；要找比产品更大的用户需求（聚会、搬家、怕被坑、带爸妈吃饭），主线再回到业务。
- **需求**：刷到的人里，有没有人会买？他在什么场景会想到你？
- **信任**：他凭什么找你，不找楼下那家？答案要落到人设、过程或案例上。

**三类顾客**：李同学把顾客分成三类——有需求还着急（约 10%）、有需求不着急、有潜在需求自己还不知道。大多数同行都在抢第一类；短视频更该慢慢「养」后两类。问用户：

> 你的顾客里，急着要的人会怎么找你（搜索、比价、团购）？不急的人刷到你什么内容会记住你？

急需的人靠价格、团购、搜索词承接，成交链条要短；不急和潜在的人靠干货、过程、故事、人设养，要反复出现。这个比例决定第五步的形式和议程分配。

**2. 用户定位：要获得谁？** 李同学认为这是最重要的一项，「千万不要陷入自嗨」。按他的问法，列 5 个**不同领域、不同收入水平、不同场景**的候选人群，每个写成具体的一个人：

```markdown
1. <谁>（<哪里/多大/收入或身份>）——在<什么场景>会想到你——他现在去找谁——付得起<客单价>吗
```

推荐 1～2 个最接近主变现、付得起客单价的，问用户：**「你最想让哪一个人刷到你？」**——这是判断点，停下等他选。用户担心切太细客户变少时，告诉他李同学的话：抖音上「再小的群体都是很大的群体」。

**3. 价值定位：你能给他什么？** 一句话，写成用户得到的东西（省钱、放心、面子、解压、少踩坑），不写「我们很专业」。

### 第四步：找空位（核心）

从下面六个方向各想 1 个候选（粗定位时只想 2～3 个最顺手的）。每个候选必须用到第一步里用户的真实信息：

| 方向 | 问自己 |
|---|---|
| 区域空位 | 在他能服务的范围里，这个品类有没有还没人认真做的区域？ |
| 行业细分空位 | 能不能从大类里切一个更窄的品类、场景或问题，让他成为第一个？ |
| 人群空位 | 能不能只服务第三步选中的那一类人，把话说到他心里？ |
| 形式空位 | 同行都在拍什么？同样的东西换一种更像用户世界的拍法（过程、现场、对比、情景）？ |
| 身份空位 | 同样的内容，换一个用户更愿意亲近的身份讲（「张总」变「隔壁阿姨的儿子」）？身份必须是他本来就是的人。 |
| 跨界融合 | 他过去的行业、经历、特长，和现在的生意能不能叠出别人没有的东西？ |

用**三个条件**筛每个候选，三个都过才算空位：

| 条件 | 检查 | 不过的常见情况 |
|---|---|---|
| 有人要 | 第三步选中的那个人，会因为这个差异来找他、付得起客单价吗？ | 「重庆唯一的分子料理火锅」——没人做，因为没人要 |
| 没人占 | 同城/同类里，用户脑子里是不是还没有一个现成的第一名？ | 已经有头部号在做同一件事 |
| 我占得住 | 他有真实的经历、手艺、资源或时间撑得住 60 条吗？ | 身份是编的，或需要他天天做他做不到的事 |

输出 2～3 个过关候选，每个一行写清三条件依据，标出推荐顺序，然后问：

> 你选哪一个做主空位？也可以说哪个最不像你。

这是判断点，停下等他选。只留 **1 个主空位**；其他写进「备选」。

### 第五步：定人设

李同学说人设是「你是谁、你要做什么样的人生、代表什么价值观」，靠事件打出来，不靠自己说。人设要真：可以塑造、可以放大，不能骗。按下面四步做，一次问一个问题。

**1. 从真实材料里挖**（选两三个问，能从前面回答里读出来的不再问）：

- 干这行这些年，你最看不惯同行或行业里的什么做法？
- 你最愿意替哪种客人说话？有没有一次你替客人出头、或者宁可不赚也没做的事？
- 你身上有什么别人一眼能记住的习惯、口头禅或缺点？
- 你为什么干这行？中间最难的一段是什么？

**2. 写 2 个人设候选**，每个写清五项：

| 项 | 写法 | 检查 |
|---|---|---|
| 价值观 | 「一个……的人」，例如「一个不让业主多花冤枉钱的老师傅」，不写职业名 | 去掉行业词还能看出他是什么样的人 |
| 帮谁说话 | 就是第三步选中的目标用户 | 和目标用户对不上，换候选 |
| 反对什么 | 让目标用户吃亏的做法（乱加价、偷工、套路办卡），只反对做法，不点名具体同行或个人 | 李同学：支持什么不一定有人设，反对什么更容易立住；和事佬很难有真朋友 |
| 真实的一面 | 一个缺点或真实习惯（嘴笨、脾气急、爱较真） | 全是优点的人设立不住 |
| 撑得住吗 | 他平时本来就这样做吗？能不能拍出 10 件这样的事？ | 要靠演才能做到，淘汰 |

**3. 用一件事体现人设**：给每个候选配一张事件卡，事件必须是用户讲过的真事，没讲过写【待补】：

```markdown
事件：<哪天、在哪、遇到什么事>
他做了什么：<一个具体动作，能拍出来>
用户看完自己得出：<他是一个……的人>
不能出现的话：「我很专业」「我很负责」「我很真诚」这类自夸
```

检查：把事件里的形容词全删掉，只留动作，观众还能不能看出他是什么样的人？看不出，换一件事。

问用户选哪个人设。这是判断点，停下等他选。

**4. 风格**：用 3 个词写用户记住他的表达气质（例如「直、土、不装」），要和人设一致。

### 第六步：定元素、形式、平台和账号议程

**1. 元素清单——用什么筛人**

李同学：「什么元素吸引什么人。」场景、台词、道具、金额都在替他筛选用户：在农村自建房烤羊吸引自建房客户，在别墅烤羊吸引别墅客户。逐项填，每个元素都要指向第三步选中的目标用户：

| 元素 | 问什么 | 例子（示意） |
|---|---|---|
| 身份 | 画面里的老板和客人是谁？ | 带孩子的宝妈、刚交房的业主、本地老街坊 |
| 场景 | 在哪拍？ | 老小区毛坯房、写字楼下午茶时间、社区菜市场旁的店 |
| 地域 | 怎么让人一眼看出是本地？ | 方言、地名、街景、本地口头语 |
| 金额 | 出现什么价位？ | 「人均 60」「三万块翻新厨房」——要和客单价对得上 |
| 道具与台词 | 什么东西、哪句话会让目标用户觉得「说的是我」？ | 业主手里的报价单、宝妈推的婴儿车 |

检查两条：元素吸引来的人付得起客单价吗？会不会只吸引看热闹的人（例如金额远高于他的客单价，只引来围观）？对不上的元素换掉。用户想扩大流量时，可以在元素上做大需求，主线和金额仍回到他的生意。

**2. 形式**：口播／过程实拍／探店或上门现场／情景剧／对比测评，选 1 个主形式，说明为什么适合他（出镜意愿、时间、店里有没有可拍的现场、第三步的信任深浅）。信任要求高的生意，优先过程和现场。

**3. 平台**：默认抖音。同一条作品可以同时发视频号和小红书，不违规；抖音跑得动的内容平移过去通常更容易。下列情况建议加视频号：目标用户年龄偏大（李同学观察视频号获客强、用户年龄偏大）、以后要做直播预约（视频号的直播预约提醒比抖音强）。用户想因为「抖音没流量」换平台时，提醒他李同学的判断：平台只是阵地，能带走的是获取流量和转化的能力；先按第八步的节点复盘，再决定要不要加平台。

**4. 账号议程**：定位能不能被记住，取决于反复讲什么。写 3 个账号议程——这个号以后反复讲的 3 件事，每件写清：

```markdown
议程<n>：<反复讲的这件事>
服务哪类顾客：急需／不急／潜在
这条线的目的：引流（让更多人刷到）／信任（让人认识你）／成交（让人来找你）
用到的元素：<从元素清单里选>
例子选题：<一个，不展开写>
```

李同学：一条视频不能同时扛流量、成交和人设，每条目的不同，合在一起才变现。3 个议程至少有一个做引流、一个做信任。

**5. 账号门面**（按李同学的账号搭建要求，给建议，用户自己改）：

- 昵称：自己的名字 + 行业，门店可以带上店名，不能只有店名。
- 头像：生活照，笑、近一点，不用西装证件照。
- 背景图：门店、团队或工作现场，不堆营销字。
- 置顶三条：第一条个人故事（为什么干这行），第二条产品、团队或门店介绍，第三条以后换成点赞最多、评论区不挨骂的那条。
- 可选：一句每条都说的固定开场或口头禅，反复说到被人记住。

### 第七步：一句话定位与交付

先写一句话定位：

> 在<用户>眼里，我是<区域／类别>里<唯一／第一个>做<差异>的<人设>。

**「唯一／第一个」要有依据**：主空位的「没人占」是用户亲自查过的，才能写「唯一／第一个」；还是【待查】时，推荐不带比较的版本（例如「当过 8 年监理、专盯老房水电防水的装修老板」），带「第一个」的版本只能作为备选，并注明查过再用。

**职业介绍检查**：在句子里找主空位的差异词（区域、细分、人群、形式、身份或跨界）；找不到，或者去掉职业名后剩下的说不出差异，说明主空位没落进去，回到第四步。卡头「账号定位」在最后一个判断点之前写「未定」，这是预期的。

问用户用哪一版。这是判断点，停下等他选。然后交付：

### 第八步：前 60 条怎么练、怎么验证

李同学：新号先定**数量目标**，不定结果目标——没有数量就没有感知，没有感知就没法迭代；做好 60 条不火的准备。把下面这段接在交付后面：

```markdown
## 怎么验证这个定位（定位是走出来的）

节奏：底线两天一条，能做到就一天一条。

- 第 1～10 条：先拍置顶三条里的个人故事和门店介绍；其余在 3 个议程里轮着拍，每个议程至少 2 条，看哪条线拍得顺、拍得出。
- 第 11～30 条：只讲 3 个议程，不追热点跑题。
- 每条发完记三个数：咨询和私信几个、来问的人是不是目标用户、有没有人提到你的差异（例如「是那个只做××的吗」）。播放量只看趋势，复盘看咨询。
- 第 30 条复盘：按下表调整一次。
- 第 60 条复盘：再调一次；已经发了一批内容，可以用 `li-agenda-setting` 检查账号印象有没有跑偏。
```

第 30 条和第 60 条的调整规则：

| 看到的信号 | 说明什么 | 怎么改 |
|---|---|---|
| 有播放、没咨询 | 流量有了，需求或信任没接上 | 检查元素是不是吸引了看热闹的人；加信任线（过程、案例、人设事件）；主页和置顶有没有讲清做什么 |
| 有咨询，来的不是目标用户 | 元素筛错了人，或者真实需求在别处 | 来的人付得起客单价、你也接得住，就按来的人改用户定位；否则换元素 |
| 来的是目标用户，没人提差异 | 主空位没被记住 | 让差异词更早、更反复出现；还不行换形式或换备选空位 |
| 某个议程明显比另外两个好 | 这条线跑通了 | 加大这条线的比例，另两条保留但减少；一个系列能跑很久，跑通后再试新系列 |
| 三个议程都拍不下去 | 「我占得住」不成立 | 回第四步换一个更贴近他真实经历的空位 |
| 播放、咨询都很少 | 样本还不够，或需求太小 | 没到 30 条不改定位，先检查是不是只拍了产品；到 30 条再按「找更大的需求」调流量线 |

调整只改一项再看下一轮，不一次全推翻。

## 质量检查

- 一句话定位里是否能找到主空位的差异词？
- 「没人占」还是【待查】时，推荐的一句话定位里是否没有「唯一／第一个」？
- 「同城没人做」之类的判断是否来自用户亲自查过的事实，否则标了【待查】？
- 变现链路是否写清主变现、客单价（或【待补】）、成交路径和信任深浅，并过了流量、需求、信任三查？
- 主空位是否同时写清了三条件依据，且用到了用户的真实经历或资源？
- 是否只留了 1 个主空位，没有把九个小定位全填满？
- 人设是否写成价值观，帮的就是目标用户，反对的是做法，没有点名具体的人？
- 人设事件是否是用户讲过的真事，删掉形容词后还能看出人设？
- 元素是否都指向目标用户，金额是否和客单价对得上？
- 3 个账号议程是否标了服务哪类顾客和目的，至少有一个引流、一个信任？
- 目标用户、主空位、人设、最终一句话是否都由用户选定？
- 是否没有承诺播放量、粉丝数和获客数？
- 交付是否包含数量节奏、每条要记的信号、30／60 条复盘和调整规则？

## 流水线衔接：内容卡与下一步

本技能是李同学「一步一技能」12 步中的第 1 步「账号定位」。单独使用时照常执行上文流程；从 `li` 主入口或上一步「继续」进来时，按下面衔接。

**内容卡**：用户当前工作目录里的 `内容卡_<主题>.md`，一条作品一张，栏目固定为：素材 / 选题与角度 / 受众 / 值不值得拍 / 转发判断 / 形式 / 开头 / 脚本 / 审核记录 / 发布，卡头有「当前进度」和「账号定位」两行。

- 开始前查找 `内容卡_*.md`：有一张就读取，沿用已确认的内容，不让用户重复提交；有多张先问是哪一条；用户粘贴了「交接卡」就以它为准。没有卡时，在用户做出第一个确认后新建，主题先写「<店名>第一条」，空栏目写「（待填）」。新卡开头三行固定为：`# 内容卡｜<主题>`、`> 当前进度：第 1 步 账号定位（<日期>）`、`> 账号定位：<一句话定位；没有写「未定」>`。
- 读卡时：一张卡记录一条作品；账号定位只写在当前这张卡的卡头，不替用户改其他卡。卡头「账号定位」已有内容时，先问用户是重新定位还是沿用。
- 本技能只更新卡头「账号定位」一行（写用户确认的一句话定位），以及卡头「当前进度」；其他栏目只读。完整的定位交付（含变现链路、人设、元素、账号议程、门面和验证节点）另存为当前目录的 `账号定位_<店名>.md`，供以后每张新卡复用。发现与其他栏目矛盾时告诉用户，由用户决定。只写用户确认过的短结论，不贴完整分析。
- 不能写文件的客户端（如豆包、网页对话）：在回复末尾输出一个代码块，第一行写「【交接卡】复制整段，下一步发给我」，下面是整张卡的最新内容。

**带练模式（默认）**：目标用户、主空位、人设和最终一句话定位由用户确认——到这些判断点必须停下，给出选项和推荐，等用户选。用户选完才更新内容卡并输出下面的结尾。用户回复「继续」时，定位并读取下一步技能的 SKILL.md（宿主已发现的技能路径，或同级目录按机器名称查找），带着内容卡进入；不越过用户的选择自动连跑。
